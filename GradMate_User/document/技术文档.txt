# GradMate 考研助手 - 技术文档

## 📋 项目概述

GradMate 是一款基于前后端分离架构的考研助手应用，采用 uni-app 跨平台前端框架和 Spring Boot 后端框架，支持微信小程序、H5 和 APP 多端部署。

---

## 🏗️ 技术架构

### 整体架构
```
┌─────────────────────────────────────────┐
│           前端层 (uni-app)              │
│  ┌──────────┬──────────┬──────────┐    │
│  │ 微信小程序 │   H5     │   APP    │    │
│  └──────────┴──────────┴──────────┘    │
└─────────────────────────────────────────┘
                    ↓ HTTP/HTTPS
┌─────────────────────────────────────────┐
│         后端层 (Spring Boot)            │
│  ┌──────────────────────────────────┐  │
│  │      RESTful API 接口层          │  │
│  ├──────────────────────────────────┤  │
│  │      业务逻辑层 (Service)        │  │
│  ├──────────────────────────────────┤  │
│  │    数据访问层 (MyBatis Plus)     │  │
│  └──────────────────────────────────┘  │
└─────────────────────────────────────────┘
                    ↓ JDBC
┌─────────────────────────────────────────┐
│          数据层 (MySQL)                 │
└─────────────────────────────────────────┘
                    ↓ API
┌─────────────────────────────────────────┐
│       AI 服务 (火山引擎 Doubao)         │
└─────────────────────────────────────────┘
```

## 🔌 API 接口设计

### 接口规范

#### 请求格式
- **Base URL**：`http://localhost:9090/api`
- **Content-Type**：application/json
- **请求方法**：GET, POST, PUT, DELETE

#### 响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 核心接口

#### 用户模块
- `POST /user/register`：用户注册
- `POST /user/login`：用户登录
- `PUT /user/update`：更新用户信息
- `GET /user/info/{id}`：获取用户信息
- `PUT /user/target`：设置目标院校专业
- `GET /user/target/{id}`：获取目标详情

#### 院校模块
- `GET /school/list`：院校列表（分页、筛选）
- `GET /school/{id}`：院校详情
- `GET /school/search`：院校搜索

#### 专业模块
- `GET /major/list`：专业列表
- `GET /major/{id}`：专业详情
- `GET /major/school/{schoolName}`：按院校查询专业
- `GET /major/search`：专业搜索

#### 资讯模块
- `GET /info/mixed/list`：混合资讯列表
- `GET /brochure/list`：招生简章列表
- `GET /information/list`：校园资讯列表
- `GET /adjust/list`：调剂通知列表

#### 学习模块
- `GET /todo/list`：任务列表
- `POST /todo/add`：添加任务
- `PUT /todo/update`：更新任务
- `DELETE /todo/delete/{id}`：删除任务
- `GET /study/stats`：学习统计
- `POST /study/record`：添加学习记录

#### 收藏模块
- `GET /favorite/list`：收藏列表
- `GET /favorite/count`：收藏数量统计
- `POST /favorite/add`：添加收藏
- `GET /favorite/remove`：取消收藏

#### AI 模块
- `POST /ai/chat`：AI 对话（流式响应）

## 🤖 AI 集成方案

### AI 服务提供商
- **火山引擎 Doubao**：字节跳动大语言模型

### 集成框架
- **LangChain4j**：Java AI 应用开发框架
  - 统一的 AI 模型接口
  - 流式响应支持
  - 对话历史管理

### 实现方式

#### 后端实现
```java
// 使用 LangChain4j 集成火山引擎
StreamingChatLanguageModel model = VolcEngineChatModel.builder()
    .apiKey(apiKey)
    .modelName("doubao-pro-32k")
    .build();

// 流式响应
model.generate(messages, new StreamingResponseHandler<>() {
    @Override
    public void onNext(String token) {
        // 发送 SSE 事件
        emitter.send(token);
    }
});
```

#### 前端实现
```javascript
// SSE 流式接收
const eventSource = new EventSource(url);
eventSource.onmessage = (event) => {
    // 逐字显示 AI 回复
    aiMessage += event.data;
};
```

### 功能特性
- **流式响应**：逐字显示，提升用户体验
- **上下文管理**：支持多轮对话
- **Markdown 渲染**：支持富文本格式
- **错误处理**：网络异常和超时处理

## 🎯 技术选型理由

### 前端选型
- **uni-app**：一套代码，多端运行，降低开发成本
- **Vue 3**：性能优秀，生态完善，学习曲线平缓
- **Composition API**：代码组织更灵活，逻辑复用更方便

### 后端选型
- **Spring Boot**：快速开发，约定优于配置，生态成熟
- **MyBatis Plus**：简化 CRUD 操作，提高开发效率
- **MySQL**：成熟稳定，性能优秀，社区活跃
- **LangChain4j**：统一 AI 接口，简化 AI 集成

### AI 选型
- **火山引擎 Doubao**：国内服务，响应快速，价格合理
