# 找专业模块测试指南

## 前置条件检查

### 1. 检查数据库表是否存在
```bash
mysql -uroot -pA123456 -D gradmate -e "SHOW TABLES LIKE 'major_category';"
```
预期输出：
```
+-------------------------------+
| Tables_in_gradmate (major_ca%) |
+-------------------------------+
| major_category                |
+-------------------------------+
```

### 2. 检查数据是否导入成功
```bash
mysql -uroot -pA123456 -D gradmate -e "SELECT COUNT(*) as total, degree_type FROM major_category GROUP BY degree_type;"
```
预期输出：
```
+-------+--------------+
| total | degree_type  |
+-------+--------------+
|  2318 | academic     |
|   227 | professional |
+-------+--------------+
```

## 后端测试

### 1. 启动Spring Boot应用
在IDE中运行 `GradMateSpringBootApplication.java` 或使用命令：
```bash
cd GradMate_SpringBoot
mvn spring-boot:run
```

等待看到类似输出：
```
Started GradMateSpringBootApplication in X.XXX seconds
```

### 2. 测试API接口

#### 测试1：查询经济学门类所有专业（学硕+专硕）
在浏览器中访问：
```
http://localhost:9090/api/major/disciplines-v2?categoryCode=02
```

预期结果：
- 返回JSON数据
- code: 200
- data数组包含多个一级学科
- 包含学硕（0201、0202、0270）和专硕（0251-0259）

#### 测试2：查询经济学门类学硕专业
```
http://localhost:9090/api/major/disciplines-v2?categoryCode=02&degreeType=academic
```

预期结果：
- 只返回学硕专业
- 包含3个一级学科：
  - 0201 理论经济学（32个专业）
  - 0202 应用经济学（82个专业）
  - 0270 统计学（2个专业）

#### 测试3：查询经济学门类专硕专业
```
http://localhost:9090/api/major/disciplines-v2?categoryCode=02&degreeType=professional
```

预期结果：
- 只返回专硕专业
- 包含10个专业：金融、应用统计、税务、国际商务、保险、资产评估、数字经济、技术转移、数据科学、碳经济

#### 测试4：查询其他学科门类
```
http://localhost:9090/api/major/disciplines-v2?categoryCode=01  # 哲学
http://localhost:9090/api/major/disciplines-v2?categoryCode=03  # 法学
http://localhost:9090/api/major/disciplines-v2?categoryCode=08  # 工学
```

## 前端测试

### 1. 启动前端应用
在HBuilderX中：
- 打开项目 `GradMate_Uniapp`
- 运行 → 运行到浏览器 → Chrome

### 2. 导航到找专业页面
- 点击底部导航栏"找专业"
- 或直接访问：`pages/major/search`

### 3. 测试功能点

#### 功能1：学科门类切换
- 点击左侧不同的学科门类（哲学、经济学、法学等）
- 预期：右侧显示对应门类的一级学科和专业列表
- 预期：切换时有加载状态

#### 功能2：学硕/专硕切换
- 点击顶部"学硕"标签
- 预期：只显示学硕专业（代码第4位不是5）
- 点击顶部"专硕"标签
- 预期：只显示专硕专业（代码第4位是5）

#### 功能3：一级学科展开/收起
- 点击一级学科标题（如"理论经济学"）
- 预期：展开显示该学科下的所有专业
- 再次点击
- 预期：收起专业列表

#### 功能4：专业详情跳转
- 点击具体专业（如"政治经济学"）
- 预期：跳转到专业详情页（如果已实现）
- 或显示"功能开发中"提示

- 预期：滚动流畅

## 常见问题排查

### 问题1：API返回400错误
原因：后端服务未启动或端口被占用
解决：
1. 检查Spring Boot是否启动成功
2. 检查9090端口是否被占用
3. 查看后端控制台错误日志

### 问题2：前端显示"加载失败"
原因：前端无法连接后端
解决：
1. 检查后端服务是否启动
2. 检查前端API地址是否正确（http://localhost:9090）
3. 检查浏览器控制台Network错误

### 问题3：数据为空
原因：数据库表未创建或数据未导入
解决：
1. 运行前置条件检查命令
2. 重新执行数据导入脚本
3. 检查数据库连接配置

### 问题4：学硕/专硕切换无效
原因：前端未正确传递degreeType参数
解决：
1. 检查浏览器Network标签，查看请求参数
2. 确认degreeType值为"academic"或"professional"
3. 检查后端日志，确认接收到的参数
