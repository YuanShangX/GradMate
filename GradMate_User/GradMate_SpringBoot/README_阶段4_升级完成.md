## 使用流程

### 1. 添加任务
1. 在任务页面点击右下角"+"按钮
2. 输入任务内容
3. 选择预计时长（15/25/30/45/60/90/120分钟）
4. 选择优先级（低/中/高）
5. 点击"确定"添加

### 2. 开始专注
1. 在任务卡片上点击"开始"按钮
2. 进入专注计时页面
3. 倒计时开始，显示激励语句
4. 可以暂停/继续/停止

### 3. 完成专注
- 倒计时结束后自动记录学习时长
- 任务自动标记为已完成
- 显示完成提示和震动反馈

## 技术亮点

### 1. 渐变背景自动循环
```javascript
getGradient(index) {
  return this.gradients[index % this.gradients.length];
```
