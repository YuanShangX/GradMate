# Spring Boot 服务启动指南

## 🚀 快速启动

### 方式1: 使用IDEA(推荐)
1. 打开IDEA
2. 找到 `GradMateSpringBootApplication.java`
3. 右键 -> Run 'GradMateSpringBootApplication'
4. 等待启动完成

### 方式2: 使用Maven命令
```bash
cd GradMate_SpringBoot
mvn spring-boot:run
```

### 方式3: 使用编译后的jar包
```bash
cd GradMate_SpringBoot
mvn clean package
java -jar target/GradMate_SpringBoot-0.0.1-SNAPSHOT.jar
```

## ⚠️ 重要提示

**每次修改Controller代码后,必须重启服务!**

新增或修改的接口只有在服务重启后才会生效。

---

## 🐛 常见问题

### 端口被占用
```
Error: Port 9090 is already in use
```

**解决方法**:
1. 找到占用端口的进程: `netstat -ano | findstr 9090`
2. 结束进程: `taskkill /PID <进程ID> /F`
3. 重新启动服务

### 数据库连接失败
```
Error: Could not connect to database
```

**解决方法**:
1. 确认MySQL服务已启动
2. 检查数据库配置(application.properties)
3. 验证用户名密码正确
