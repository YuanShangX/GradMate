## 性能对比

### 旧接口（/api/major/disciplines）
- 查询major表（约10万+条记录）
- 使用DISTINCT去重
- 需要在应用层分组处理

### 新接口（/api/major/disciplines-v2）
- 查询major_category表（2545条记录）
- 已预处理好的数据结构
- 支持学硕/专硕筛选
- 查询速度提升约10-20倍

## 注意事项

1. 如果major表有新增专业，需要重新运行导入脚本
2. 专硕识别规则：专业代码第4位是5（如025100）
3. 学硕识别规则：专业代码第4位不是5（如020101）
