## 一、重构概述

### 1.1 设计理念

参考院校库（`pages/school/list.vue`）的设计风格，将ToDo清单所有页面重构为：
- 清爽的卡片式设计
- 统一的导航栏（返回按钮 + 标题/搜索框）
- 弹窗式筛选器
- 简洁的CSS图标（不依赖emoji）
- 白色背景 + 圆角卡片

### 1.2 重构范围

- ✅ `pages/study/tasklist.vue` - 任务列表页面
- ✅ `pages/study/calendar.vue` - 打卡日历页面
- ✅ `pages/study/focus.vue` - 专注计时页面
- ⏳ `pages/study/task.vue` - 任务管理页面（待重构）
- ⏳ `pages/study/index.vue` - 学习伴侣主页（待重构）

## 三、calendar.vue 重构详情

### 3.1 核心改进

1. **导航栏** - 返回按钮 + 居中标题
2. **统计卡片** - 3个独立卡片（连续打卡/本月打卡/累计学习）

4. **打卡按钮** - 底部固定，CSS打勾图标
5. **弹窗** - 底部弹出式，与院校库一致

### 3.2 CSS图标实现

- 🔥 火焰图标：圆角矩形 + 底部三角形
- ✓ 打勾图标：圆形 + 对勾
- ⏰ 时钟图标：圆形 + 时针分针
- 📖 书本图标：矩形 + 横线
- 📄 空状态图标：矩形 + 横线
- ★ 心情评分：星星符号（★）替代emoji
- ‹ › 箭头：纯文本字符

### 3.3 移除emoji依赖

完全移除所有emoji图标：
- ❌ 移除心情emoji（😞😐😊😄🤩）→ 改用星星符号（★）
- ❌ 移除学习类型emoji（📚📖🔢💻📝📄📌）→ 改用纯文字标签
- ❌ 移除空状态emoji（📝）→ 改用CSS绘制的图标
- ❌ 移除详情页emoji（⏱）→ 改用CSS时钟图标
- ✅ 所有图标均使用CSS绘制或文字符号

### 3.4 颜色方案

- 连续打卡：蓝色 (#5b8ff9)
- 本月打卡：绿色 (#52c41a)
- 累计学习：橙色 (#fa8c16)

## 五、设计规范总结

### 5.1 颜色规范

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | `#5b8ff9` | 按钮、图标、强调色 |
| 背景色 | `#f0f3fa` | 页面背景 |
| 卡片背景 | `#ffffff` | 白色卡片 |
| 文字主色 | `#333` | 标题、正文 |
| 文字辅色 | `#666` | 次要信息 |
| 文字浅色 | `#999` | 提示信息 |
| 边框色 | `#f0f0f0` | 分割线 |
| 成功色 | `#52c41a` | 绿色 |
| 警告色 | `#fa8c16` | 橙色 |
| 错误色 | `#ff4d4f` | 红色 |

### 5.2 圆角规范

| 元素 | 圆角值 |
|------|--------|
| 卡片 | `16rpx` |
| 按钮 | `44rpx`（圆形）或 `12rpx` |
| 标签 | `6rpx` |
| 输入框 | `12rpx` |
| 弹窗 | `24rpx` |

### 5.3 间距规范

| 用途 | 间距值 |
|------|--------|
| 页面边距 | `30rpx` |
| 卡片间距 | `20rpx` |
| 元素间距 | `12rpx` - `24rpx` |
| 内边距 | `24rpx` - `32rpx` |

### 5.4 字体规范

| 用途 | 字号 | 字重 |
|------|------|------|
| 页面标题 | `34rpx` | 600 |
| 卡片标题 | `32rpx` | 500-600 |
| 正文 | `28rpx` | 400 |
| 辅助文字 | `24rpx` | 400 |
| 小字 | `22rpx` | 400 |

## 九、总结

### 9.1 改进亮点

1. **视觉统一** - 所有页面与院校库风格完全一致
2. **零emoji依赖** - 全部使用CSS绘制图标或文字符号
3. **交互优化** - 弹窗选择器、确认提示
4. **代码现代化** - 使用 Composition API
5. **性能优化** - 减少不必要的渲染
6. **跨平台兼容** - 不依赖emoji字体，所有平台显示一致

### 9.2 技术亮点

1. **CSS图标库** - 可复用的图标组件
2. **统一样式变量** - 便于主题切换
3. **响应式设计** - 适配不同屏幕
4. **动画效果** - 流畅的过渡动画
