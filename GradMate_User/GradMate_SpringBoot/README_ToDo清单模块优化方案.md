# ToDo清单模块优化方案

## 当前问题分析

### 1. 功能问题
- ❌ 任务编辑功能未实现（只有删除）
- ❌ 任务拖拽排序功能缺失
- ❌ 任务分类/标签功能缺失
- ❌ 重复任务功能缺失
- ❌ 任务提醒功能缺失
- ❌ 子任务功能缺失
- ❌ 任务搜索功能缺失
- ❌ 任务统计不够详细

### 2. UI/UX问题
- ❌ 两个页面功能重复（tasklist.vue 和 task.vue）
- ❌ 渐变色卡片虽然好看但不够实用
- ❌ 缺少快速操作（滑动删除、长按菜单）
- ❌ 任务状态不够直观
- ❌ 优先级展示不明显
- ❌ 缺少任务筛选功能

### 3. 数据结构问题
- ❌ 缺少estimatedDuration字段（预计时长）
- ❌ 缺少actualDuration字段（实际时长）
- ❌ 缺少tags字段（标签）
- ❌ 缺少parentTaskId字段（父任务ID，用于子任务）
- ❌ 缺少repeatType字段（重复类型）

## 优化方案

### 阶段1：核心功能完善（优先级：高）

#### 1.1 统一页面结构
**目标**：合并tasklist.vue和task.vue，创建一个功能完整的任务管理页面

**新页面结构**：
```
┌─────────────────────────────────┐
│  顶部导航栏                      │
│  [返回] ToDo清单 [菜单] [添加]   │
├─────────────────────────────────┤
│  日期选择器 & 快速筛选           │
│  [今天] [明天] [本周] [全部]     │
├─────────────────────────────────┤
│  任务统计卡片                    │
│  今日: 3/8完成  本周: 15/20完成  │
├─────────────────────────────────┤
│  筛选标签栏                      │
│  [全部] [待办] [进行中] [已完成] │
├─────────────────────────────────┤
│  任务列表                        │
│  ┌───────────────────────────┐  │
│  │ ☐ 任务标题                │  │
│  │   📅 今天 ⏰ 25分钟 🏷️ 学习│  │
│  │   [开始] [编辑] [删除]    │  │
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │ ☑ 已完成的任务            │  │
│  │   📅 今天 ⏰ 30分钟        │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

#### 1.2 完善任务CRUD功能

**新增功能**：
1. ✅ 任务编辑（修改标题、时长、优先级、标签）
2. ✅ 任务复制
3. ✅ 批量操作（批量删除、批量完成）
4. ✅ 任务搜索
5. ✅ 任务排序（按优先级、时间、创建时间）

**交互优化**：
- 左滑显示快捷操作（完成、编辑、删除）
- 长按进入多选模式
- 点击checkbox快速完成/取消完成
- 拖拽排序

#### 1.3 数据库表结构优化

**新增字段**：
```sql
ALTER TABLE daily_task ADD COLUMN estimated_duration INT DEFAULT 25 COMMENT '预计时长(分钟)';
ALTER TABLE daily_task ADD COLUMN actual_duration INT DEFAULT 0 COMMENT '实际时长(分钟)';
ALTER TABLE daily_task ADD COLUMN tags VARCHAR(200) COMMENT '标签(逗号分隔)';
ALTER TABLE daily_task ADD COLUMN parent_task_id BIGINT COMMENT '父任务ID';
ALTER TABLE daily_task ADD COLUMN repeat_type VARCHAR(20) COMMENT '重复类型: none/daily/weekly/monthly';
ALTER TABLE daily_task ADD COLUMN sort_order INT DEFAULT 0 COMMENT '排序顺序';
ALTER TABLE daily_task ADD COLUMN description TEXT COMMENT '任务描述';
```

## 技术实现要点

### 前端优化
1. 使用虚拟列表优化长列表性能
2. 添加骨架屏提升加载体验
3. 使用防抖/节流优化搜索和排序
4. 添加下拉刷新和上拉加载
5. 使用本地缓存减少请求

### 后端优化
1. 添加任务批量操作接口
2. 优化查询性能（添加索引）
3. 添加任务统计接口
4. 实现任务搜索接口
5. 添加任务导出功能
