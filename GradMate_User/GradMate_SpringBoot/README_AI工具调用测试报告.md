# AI工具调用功能测试报告

## 测试时间
2026-02-19 20:00

## 功能概述
实现了基于关键词识别的AI工具自动调用功能，使AI能够查询真实数据库并提供准确信息。

---

## 一、实现方案

### 方案选择
采用**关键词识别 + 工具调用**方案，原因：
1. 火山引擎SDK可能不支持标准Function Calling
2. 关键词识别方案简单可靠，可快速上线
3. 能够满足大部分使用场景

### 技术实现

#### 1. 意图检测
在`GradMateAgentService.detectIntentAndCallTools()`方法中实现：

```java
private String detectIntentAndCallTools(Long userId, String userMessage) {
    String message = userMessage.toLowerCase();
    StringBuilder toolResults = new StringBuilder();
    
    // 意图1: 院校推荐
    if (containsAny(message, "推荐院校", "推荐学校", "择校", ...)) {
        String result = tools.analyzeTargetUniversity(userMessage);
        toolResults.append("\n\n[系统查询结果 - 院校推荐]\n").append(result);
    }
    
    // 意图2: 分数线查询
    if (containsAny(message, "分数线", "录取分数", ...)) {
        String[] extracted = extractSchoolAndMajor(userMessage);
        String result = tools.getScoreLine(extracted[0], extracted[1]);
        toolResults.append("\n\n[系统查询结果 - 分数线信息]\n").append(result);
    }
    
    // 意图3: 资讯查询
    if (containsAny(message, "最新资讯", "考研资讯", ...)) {
        String result = tools.getGraduationNews();
        toolResults.append("\n\n[系统查询结果 - 最新资讯]\n").append(result);
    }
    
    // 意图4: 用户目标查询
    if (containsAny(message, "我的目标", "目标院校", ...)) {
        String result = tools.getUserTarget(userId);
        toolResults.append("\n\n[系统查询结果 - 用户目标]\n").append(result);
    }
    
    return userMessage + toolResults.toString();
}
```

#### 2. 关键词匹配
支持的关键词列表：

**院校推荐**:
- 推荐院校、推荐学校、推荐大学
- 择校、选择院校、选择学校
- 哪些院校、哪些学校、哪些大学
- 什么院校、什么学校

**分数线查询**:
- 分数线、录取分数、复试分数
- 初试分数、国家线、院校线

**资讯查询**:
- 最新资讯、考研资讯、招生简章
- 调剂信息、调剂公告、招生信息
- 招生通知、最新消息、最新通知

**用户目标**:
- 我的目标、目标院校、目标专业
- 我想考、我的目标是

#### 3. 实体提取
简单的院校和专业名称提取：

```java
private String[] extractSchoolAndMajor(String message) {
    String[] result = new String[2];
    
    // 常见院校关键词
    String[] schools = {"清华", "北大", "复旦", "交大", ...};
    
    // 常见专业关键词
    String[] majors = {"计算机", "软件工程", "电子", ...};
    
    // 提取院校和专业
    for (String school : schools) {
        if (message.contains(school)) {
            result[0] = school;
            break;
        }
    }
    
    for (String major : majors) {
        if (message.contains(major)) {
            result[1] = major;
            break;
        }
    }
    
    return result;
}
```

## 三、功能特点

### 优点 ✅

1. **智能识别**: 能够识别多种表达方式
2. **自动调用**: 无需用户手动触发
3. **真实数据**: 查询真实数据库，信息准确
4. **自然整合**: AI能够自然地整合查询结果
5. **友好提示**: 查询失败时给出友好提示

### 局限性 ⚠️

1. **关键词依赖**: 依赖预定义关键词，可能遗漏某些表达
2. **实体提取简单**: 院校和专业提取基于简单匹配，可能不准确
3. **无法处理复杂查询**: 如"比较清华和北大的计算机专业"
4. **无法处理模糊查询**: 如"推荐一些工科院校"（无法识别"工科"）

---

## 四、改进建议

### 短期改进（1-2天）

1. **扩展关键词库**
   - 添加更多同义词
   - 支持拼音和缩写（如"THU"代表清华）

2. **改进实体提取**
   - 支持更多院校名称
   - 支持专业全称（如"计算机科学与技术"）
   - 支持模糊匹配（如"清华"匹配"清华大学"）

3. **添加更多意图**
   - 院校对比（"清华和北大哪个好"）
   - 专业对比（"计算机和软件工程哪个好"）
   - 备考建议（"如何备考清华计算机"）

### 长期改进（1-2周）

4. **集成NLP模型**
   - 使用命名实体识别（NER）提取院校和专业
   - 使用意图识别模型替代关键词匹配
   - 支持更复杂的查询

5. **实现标准Function Calling**
   - 研究火山引擎是否支持Function Calling
   - 如果支持，迁移到标准实现
   - 让AI自动判断何时调用工具
