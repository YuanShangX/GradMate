## 一、打卡功能测试

### 测试1：快捷时长打卡
**目的**：验证快捷时长选择功能

**步骤**：
1. 打开小程序，进入"学习"模块
2. 点击"打卡日历"
3. 点击"今日打卡"按钮
4. 选择"25分钟"快捷按钮
5. 观察按钮是否高亮显示
6. 选择学习类型"专业课"
7. 选择心情5星
8. 填写备注"测试快捷打卡功能"
9. 点击"提交打卡"

**预期结果**：
- ✅ 快捷按钮点击后高亮显示
- ✅ 提交成功提示"打卡成功！"
- ✅ 手机震动反馈
- ✅ 弹窗自动关闭
- ✅ 统计数据自动更新

### 测试2：学习类型选择
**目的**：验证学习类型分类功能

**步骤**：
1. 点击"今日打卡"
2. 选择时长"30分钟"
3. 依次点击不同的学习类型：
   - 📚 专业课
   - 📖 英语
   - 🔢 数学
   - 💻 编程
   - 📝 刷题
   - 📄 阅读
   - 📌 其他
4. 观察每个类型的选中效果
5. 最终选择"英语"
6. 提交打卡

**预期结果**：
- ✅ 每个类型点击后高亮显示
- ✅ 只能选择一个类型
- ✅ 图标和文字清晰可见
- ✅ 打卡成功后保存学习类型

### 测试3：日历增强显示
**目的**：验证日历显示学习时长和心情

**步骤**：
1. 完成多次打卡（不同时长）：
   - 第1次：15分钟，心情3星
   - 第2次：60分钟，心情5星
   - 第3次：120分钟，心情4星
2. 观察日历上的日期显示
3. 检查颜色深浅是否正确
4. 检查时长显示是否正确
5. 检查心情图标是否显示

**预期结果**：
- ✅ 15分钟显示为极浅蓝色
- ✅ 60分钟显示为浅蓝色
- ✅ 120分钟显示为深蓝色
- ✅ 时长显示为"0.3h"、"1.0h"、"2.0h"
- ✅ 心情图标正确显示

### 测试4：打卡详情查看
**目的**：验证打卡详情弹窗

**步骤**：
1. 点击已打卡的日期
2. 查看详情弹窗内容
3. 检查显示的信息：
   - 学习时长
   - 今日心情
   - 学习类型
   - 学习备注
4. 点击关闭按钮

**预期结果**：
- ✅ 弹窗正确显示
- ✅ 所有信息完整显示
- ✅ 图标和文字对齐
- ✅ 关闭按钮正常工作

## 二、统计功能测试

### 测试5：核心数据展示
**目的**：验证统计数据准确性

**步骤**：
1. 进入"统计数据"页面
2. 查看核心数据卡片：
   - 累计学习时长
   - 连续打卡天数
   - 累计打卡天数
3. 手动计算验证数据

**预期结果**：
- ✅ 累计学习时长 = 所有打卡时长之和
- ✅ 连续打卡天数正确计算
- ✅ 累计打卡天数 = 打卡的总天数
- ✅ 数据格式正确（如"2.5h"）

### 测试6：本周vs上周对比
**目的**：验证周对比功能

**步骤**：
1. 查看"本周 vs 上周"卡片
2. 检查本周学习时长
3. 检查上周学习时长
4. 检查增长百分比
5. 观察增长/下降的颜色标识

**预期结果**：
- ✅ 本周时长 = 本周所有打卡之和
- ✅ 上周时长 = 上周所有打卡之和
- ✅ 增长率计算正确
- ✅ 增长显示绿色↑，下降显示红色↓
- ✅ 周范围显示正确（如"2/16 - 2/22"）

### 测试7：学习时长趋势
**目的**：验证趋势图表功能

**步骤**：
1. 查看"学习时长趋势"图表
2. 点击"7天"标签
3. 观察柱状图显示
4. 点击"30天"标签
5. 观察柱状图变化
6. 检查每个柱子的高度和数值

**预期结果**：
- ✅ 7天显示最近7天数据
- ✅ 30天显示最近30天数据
- ✅ 柱状图高度与时长成正比
- ✅ 柱子上显示具体时长
- ✅ 横轴标签正确（周一、周二...）
- ✅ 无数据时显示空状态

### 测试8：学习类型分布
**目的**：验证类型统计功能

**步骤**：
1. 完成不同类型的打卡：
   - 专业课：60分钟
   - 英语：30分钟
   - 数学：45分钟
2. 查看"学习类型分布"
3. 检查每个类型的：
   - 图标
   - 名称
   - 进度条
   - 百分比
   - 时长

**预期结果**：
- ✅ 所有类型按时长降序排列
- ✅ 进度条长度与百分比一致
- ✅ 百分比计算正确（60/135=44%）
- ✅ 时长显示正确（"1.0h"）
- ✅ 颜色区分清晰

### 测试9：学习习惯分析
**目的**：验证习惯分析功能

**步骤**：
1. 查看"学习习惯分析"卡片
2. 检查三个指标：
   - 最佳时段
   - 日均学习
   - 完成率
3. 验证数据准确性

**预期结果**：
- ✅ 最佳时段显示（当前为固定值）
- ✅ 日均学习 = 累计时长 / 累计天数
- ✅ 完成率基于目标计算
- ✅ 图标和数值对齐

## 五、接口测试

### 接口1：打卡接口
```bash
curl -X POST http://localhost:9090/study/checkin \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 1,
    "duration": 25,
    "studyType": "major",
    "mood": 5,
    "note": "测试打卡"
  }'
```

**预期响应**：
```json
{
  "code": 200,
  "message": "打卡成功",
  "data": null
}
```

### 接口2：统计数据接口
```bash
curl http://localhost:9090/study/stats?userId=1
```

**预期响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "totalDuration": 150,
    "continuousDays": 3,
    "totalDays": 5,
    "monthlyDays": 3,
    "todayChecked": true
  }
}
```

### 接口3：月度记录接口
```bash
curl "http://localhost:9090/study/record/month?userId=1&year=2026&month=2"
```

**预期响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "checkDate": "2026-02-20",
      "duration": 25,
      "studyType": "major",
      "mood": 5,
      "note": "测试打卡"
    }
  ]
}
```

### 接口4：范围记录接口
```bash
curl "http://localhost:9090/study/record/range?userId=1&startDate=2026-02-14&endDate=2026-02-20"
```
