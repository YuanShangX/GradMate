## 技术要点

### 1. 数据关联
- 资讯表通过 `school_id` 关联院校表
- Service 层自动查询并填充学校名称
- 使用缓存机制减少重复查询

### 2. 时间排序
- 所有资讯列表按 `publish_date` 降序排列
- 确保最新资讯优先展示

### 3. 外部链接处理
- 使用系统浏览器打开外部链接
- H5 环境使用 `window.open()`
- App 环境使用 `plus.runtime.openURL()`

### 4. 分页加载
- 支持下拉刷新
- 支持上拉加载更多
- 显示加载状态和"没有更多"提示

### 5. 搜索功能
- 支持按院校名称模糊搜索
- 搜索时自动重置页码
- 清除搜索按钮

## API 接口说明

### 招生简章接口

#### 1. 获取简章列表
```
GET /api/info/brochure/list
```

**请求参数**：
- `schoolId`（可选）：学校ID
- `schoolName`（可选）：学校名称（模糊查询）
- `pageNum`（默认1）：页码
- `pageSize`（默认10）：每页数量

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "schoolId": 1,
        "schoolName": "北京大学",
        "title": "2026年硕士研究生招生简章",
        "url": "https://...",
        "publishDate": "2025-09-01T00:00:00",
        "type": "brochure"
      }
    ],
    "total": 1888,
    "current": 1,
    "pages": 189
  }
}
```

#### 2. 获取简章详情
```
GET /api/info/brochure/{id}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "schoolId": 1,
    "schoolName": "北京大学",
    "title": "2026年硕士研究生招生简章",
    "url": "https://...",
    "publishDate": "2025-09-01T00:00:00",
    "type": "brochure"
  }
}
```

### 调剂公告接口

#### 1. 获取调剂公告列表
```
GET /api/info/adjust/list
```

参数和响应格式同招生简章接口，`type` 为 `adjust`。

#### 2. 获取调剂公告详情
```
GET /api/info/adjust/{id}
```

### 招生通知接口

#### 1. 获取招生通知列表
```
GET /api/info/information/list
```

参数和响应格式同招生简章接口，`type` 为 `information`。

#### 2. 获取招生通知详情
```
GET /api/info/information/{id}
```
