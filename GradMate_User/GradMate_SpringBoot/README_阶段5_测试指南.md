## 常见问题排查

### 问题1: 页面显示空白
**原因**: 路由配置错误或页面文件不存在
**解决**: 检查pages.json是否包含新页面路由

### 问题2: 任务列表为空
**原因**: 数据库没有今日任务数据
**解决**: 添加一个任务测试

### 问题3: 专注计时不工作
**原因**: 倒计时逻辑错误或页面参数传递错误
**解决**: 检查focus.vue的onLoad方法和timer逻辑

### 问题4: 统计数据显示0
**原因**: 数据库没有学习记录
**解决**: 完成一次专注或手动打卡

### 问题5: 底部导航不显示
**原因**: CSS样式问题或z-index层级问题
**解决**: 检查tasklist.vue的tabbar样式
