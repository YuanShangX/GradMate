### 1. 后端接口测试

#### 1.1 用户统计接口
**接口**: `GET /api/user/stats/{userId}`

**测试用例1**: 正常获取统计数据
```bash
curl http://localhost:9090/api/user/stats/1
```

**预期结果**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "nickname": "测试用户"
  }
}
```

**测试用例2**: 用户不存在
```bash
curl http://localhost:9090/api/user/stats/99999
```

**预期结果**:
```json
{
  "code": 500,
  "message": "用户不存在"
}
```
