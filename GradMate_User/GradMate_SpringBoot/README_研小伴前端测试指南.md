## 常见问题排查

### 问题1: 页面空白
```bash
原因: 后端服务未启动
解决: 启动Spring Boot服务
```

### 问题2: 图标不显示
```bash
原因: CSS伪元素未生效
解决: 检查浏览器兼容性
```

### 问题3: 渐变不显示
```bash
原因: 浏览器不支持
解决: 使用现代浏览器
```

### 问题4: 动画卡顿
```bash
原因: 性能问题
解决: 关闭其他应用，清理缓存
```

### 问题5: 侧边栏不滑出
```bash
原因: transition未生效
解决: 检查CSS样式
```
