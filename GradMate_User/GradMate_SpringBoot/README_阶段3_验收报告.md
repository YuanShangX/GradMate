## 技术要点完成情况

### ✅ 数据关联
- 资讯表通过 `school_id` 关联院校表
- Service 层自动查询并填充学校名称
- 使用 HashMap 缓存学校名称，提升性能

### ✅ 时间排序
- 所有资讯列表按 `publish_date` 降序排列
- 确保最新资讯优先展示

### ✅ 外部链接处理
- 使用系统浏览器打开外部链接
- H5 环境使用 `window.open()`
- App 环境使用 `plus.runtime.openURL()`

### ✅ 分页加载
- 支持下拉刷新
- 支持上拉加载更多
- 显示加载状态和"没有更多"提示

### ✅ 搜索功能
- 支持按院校名称模糊搜索
- 搜索时自动重置页码
- 清除搜索按钮

#### 测试步骤
1. 启动 Spring Boot 应用
2. 使用浏览器或 Postman 测试以下接口：

```bash

# 测试调剂公告列表
GET http://localhost:9090/api/info/adjust/list?pageNum=1&pageSize=10

# 测试招生通知列表
GET http://localhost:9090/api/info/information/list?pageNum=1&pageSize=10

# 测试详情接口
GET http://localhost:9090/api/info/brochure/1
GET http://localhost:9090/api/info/adjust/1
GET http://localhost:9090/api/info/information/1
```

#### 预期结果
- 所有接口返回 200 状态码
- 返回数据格式符合 Result 规范
- 数据包含学校名称、标题、URL、发布日期
- 分页信息正确（total、current、pages）
