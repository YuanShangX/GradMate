# 学习模块打卡入口优化说明

> 完成时间：2026-02-20  
> 优化内容：学习模块主页图标优化，移除 emoji，使用 CSS 图标

---

## 打卡按钮位置

### 1. 学习模块主页（推荐）
**路径**：`/pages/study/index.vue`

**位置**：功能网格的第4个卡片（右下角）

**特点**：
- 显示"今日打卡"文字
- 已打卡时卡片背景变为浅蓝色渐变
- 描述文字显示"已打卡"或"立即打卡"
- 点击弹出打卡弹窗

**打卡弹窗内容**：
- 学习时长（分钟）
- 今日心情（1-5星）
- 学习备注（文本框）

### 2. 打卡日历页面
**路径**：`/pages/study/calendar.vue`

**位置**：页面底部中央浮动按钮

**特点**：
- 仅在未打卡时显示
- 蓝色圆角按钮
- 点击弹出详细打卡表单

**打卡表单内容**：
- 学习时长（快捷选择 + 自定义）
- 学习类型（专业课/英语/数学等）
- 今日心情（1-5星）
- 学习备注

## 打卡流程

### 1. 从学习主页打卡

```
用户点击"今日打卡"
   ↓
弹出打卡弹窗
   ↓
填写学习时长、心情、备注
   ↓
点击"提交打卡"
   ↓
调用 POST /study/checkin
   ↓
打卡成功
   ↓
- 显示成功提示
- 震动反馈
- 刷新统计数据
- 卡片状态变为"已打卡"
```

### 2. 从日历页面打卡

```
用户进入打卡日历
   ↓
点击底部"今日打卡"按钮
   ↓
弹出详细打卡表单
   ↓
选择学习时长（快捷或自定义）
选择学习类型
选择心情
填写备注
   ↓
点击"提交打卡"
   ↓
调用 POST /study/checkin
   ↓
打卡成功
   ↓
- 日历上标记今日
- 统计数据更新
- 按钮消失
```

## 打卡接口

### 接口地址
```
POST /api/study/checkin
```

### 请求参数
```json
{
  "userId": 1,
  "studyDuration": 60,      // 学习时长（分钟）
  "focusCount": 1,          // 专注次数（可选）
  "pauseCount": 0,          // 暂停次数（可选）
  "studyType": "major",     // 学习类型（可选）
  "mood": 5,                // 心情（1-5）
  "notes": "今天学习了高数"  // 备注
}
```

### 返回数据
```json
{
  "code": 200,
  "message": "打卡成功",
  "data": {
    "id": 123,
    "userId": 1,
    "checkDate": "2026-02-20",
    "duration": 60,
    "mood": 5,
    "notes": "今天学习了高数"
  }
}
```
