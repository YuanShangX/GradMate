# 学习模块入口优化

## 完成时间
2026-02-20

## 概述
优化了学习模块的功能入口，在tasklist页面添加了快捷操作栏，在学习首页调整了功能布局，使打卡和统计功能更容易访问。

## 优化内容

### 1. tasklist页面（ToDo清单）

#### 新增快捷操作栏
在搜索栏下方添加了三个快捷入口：

```
快捷操作栏
├── 📅 打卡日历 - 跳转到calendar页面
├── 📊 统计数据 - 跳转到stats页面
└── ⏱ 专注计时 - 跳转到focus页面
```

#### 功能说明
- **打卡日历**：查看每日打卡记录，日历视图展示
- **统计数据**：查看学习统计，包括累计时长、连续天数等
- **专注计时**：快速开始专注计时，无需选择任务

#### 样式设计
- 横向排列，三个图标均匀分布
- 图标大小：48rpx
- 文字大小：24rpx
- 背景：白色，底部有分隔线

### 2. study/index页面（学习首页）

#### 功能布局调整
原来的2x2网格（4个功能）调整为：

```
功能网格（2x2）
├── 📝 每日任务 - 管理学习任务
├── 📅 打卡日历 - 记录学习历程
├── 📊 统计数据 - 查看学习统计
└── ✅ 今日打卡 - 立即打卡
```

#### 移除的功能
- 🎯 学习计划 - 移除（功能重复，已在倒计时组件中体现）

#### 保留的功能
- 倒计时卡片（顶部）
- 今日概览（统计数据）
- 激励语（底部）
- 打卡弹窗
- 学习计划弹窗（通过倒计时卡片访问）

## 功能流程

### 打卡流程
```
用户操作
├── 方式1：首页点击"今日打卡"
├── 方式2：tasklist点击"打卡日历"
└── 方式3：calendar页面点击日期

打卡弹窗
├── 输入学习时长
├── 选择心情（1-5星）
├── 填写学习备注
└── 提交打卡
    ├── 调用API：POST /study/checkin
    ├── 震动反馈
    ├── 刷新统计数据
    └── 显示成功提示
```

### 统计查看流程
```
用户操作
├── 方式1：首页点击"统计数据"
├── 方式2：tasklist点击"统计数据"
└── 方式3：首页"今日概览"查看简要统计

统计页面
├── 累计专注
│   ├── 次数
│   ├── 时长
│   └── 目标时长
├── 当日专注
│   ├── 次数
│   └── 时长
├── 专注时长分布
│   ├── 日/周/月/自定义
│   └── 图表展示
└── 专注时段分布
    └── 时段统计
```

## 相关API

### 打卡相关
- `POST /study/checkin` - 提交打卡
  ```json
  {
    "userId": 1,
    "duration": 60,
    "mood": 5,
    "note": "今天学习了数学"
  }
  ```

### 统计相关
- `GET /study/stats?userId={userId}` - 获取统计数据
  ```json
  {
    "continuousDays": 7,
    "totalDuration": 1200,
    "todayTasks": "3/5",
    "todayChecked": true
  }
  ```

### 日历相关
- `GET /study/record/month?userId={userId}&year={year}&month={month}` - 获取月度打卡记录
